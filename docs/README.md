# PlanTrack — Developer Docs

## Files in this folder

### `ai_engine.py`
Python reference implementation of the PlanTrack AI engine.  
Shows the data structures and prompt templates used by the AI Co-Pilot.

### `models.json`
AI model configuration — lists supported Gemini model IDs and their capabilities.

---

> **Note**: The live AI runs entirely in the browser via `app.js` using the Gemini API key in `config.js`. These files are reference/documentation only.
